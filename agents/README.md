# Agent Integrations

Ready-to-use skills and integrations for AI agents to work with StratMD.

## OpenClaw

### [stratmd-loader](./openclaw/stratmd-loader/)

A prompt-based skill that loads and aligns an agent with its StratMD strategy files. Drop it into your OpenClaw workspace for instant strategy governance.

**Features:**
- Automatic loading of `strategy.strat.md` and linked files
- Mandatory alignment checks before actions
- Constraint and Decision Graveyard enforcement
- Heartbeat-based reload on file changes
